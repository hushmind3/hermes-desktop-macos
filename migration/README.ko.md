# 새 맥에 설치한 뒤 덮어 복원하는 백업

대상: Apple Silicon 맥. 모델·설치 앱·실행 환경·재생성 가능한 캐시·과거 중복 백업은 제외했습니다.

## 포함한 내용

- 기본 프로필 및 9개 봇 프로필의 설정, 페르소나, 환경 변수, 인증 정보
- 대화 DB, 기억, 학습 스킬, 대기 중인 기억/스킬 변경, 예약 작업
- 플러그인 코드와 실제 설정, 플러그인 심볼릭 링크
- 텔레그램 관련 수정 및 현재 사용 중인 헤르메스 소스 전체 스냅샷
- 데스크톱 표시 설정과 로컬 UI 상태(브라우저 쿠키·기기 키체인 암호문 제외)

## 복원 순서

1. 새 맥에 Hermes를 정상 설치하고, Hermes 데스크톱 앱은 종료합니다. 기존 맥의 Telegram 게이트웨이는 새 서버를 켜기 전에 반드시 중지합니다.
2. 이 Release의 `restore-tools.zip`과 `hermes-migration.enc.part001`을 모두 받습니다. tools ZIP을 풀고, 암호화 파일을 `Restore.command`와 같은 폴더에 둡니다.
3. 별도 보관한 `Hermes-restore-key-20261029.txt`를 새 맥으로 옮깁니다. 키는 GitHub에 올리지 않았습니다. 키가 없으면 암호화 백업을 복원할 수 없습니다.
4. `Restore.command`를 실행하고 키 파일 경로를 입력합니다. macOS가 실행을 막으면 터미널에서 해당 폴더로 이동해 아래 명령을 실행합니다.

```bash
bash Restore.command /복원키/경로/Hermes-restore-key-20261029.txt
```

복원 도구는 암호와 무결성을 확인한 뒤, 현재 설치를 먼저 백업하고 공식 `hermes import`로 데이터를 복원합니다. 이어서 수정 소스 스냅샷을 복원하고, 저장된 잠금 파일에 맞춰 의존성과 데스크톱을 다시 준비합니다(인터넷 필요). 사용자 홈 경로와 내부 링크를 새 맥에 맞춥니다.

새 서버는 자동으로 켜지지 않습니다. 기존 맥의 게이트웨이를 중지한 뒤 새 맥에서 다음을 실행하세요.

```bash
hermes --profile default gateway install --force --start-now --start-on-login
```

## 새 기기에서 다시 승인할 수 있는 것

- 화면 기록·손쉬운 사용·파일 접근 같은 macOS 권한
- macOS 키체인에 묶인 로그인, 만료되거나 폐기된 OAuth 인증
- Tailscale 로그인 및 Windows 클라이언트의 새 Mac 서버 주소 연결
- 백업에서 제외한 Ollama 모델의 재다운로드

작업 파일이 별도 프로젝트 폴더에 있는 경우 그 프로젝트 폴더 자체는 이 Hermes 백업에 포함되지 않습니다. 모델 파일, 설치 앱, OS 권한을 복사하는 백업이 아닙니다.

## 검증

암호화 파일의 HMAC 및 SHA-256 확인, 잘못된 키의 복원 차단, 격리 폴더로 실제 복호화·추출, SQLite 검사, 9개 봇 설정·대화·페르소나 및 플러그인 링크 대조를 수행합니다. 새 맥 하드웨어에서 앱 설치/권한 승인까지 실행한 검증은 아닙니다.
